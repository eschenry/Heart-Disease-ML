Machine Learning Project using the UCI Heart Disease Dataset

# Heart Disease Prediction and Patient Segmentation

## Overview

This project investigates heart disease prediction using supervised learning and explores potential patient segmentation using clustering techniques.

## Dataset

UCI Heart Disease Dataset

## Models Evaluated

- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost
- SVM

## Clustering

- K-Means
- Hierarchical Clustering
- DBSCAN

## Explainability

- SHAP
- Random Forest Feature Importance

## Best Model

Random Forest

Accuracy: 0.934
ROC-AUC: 0.963
F1: 0.931
